# API types

The file [`./api-types.ts`](./api-types.ts) is **autogenerated** from the
Django REST Framework OpenAPI schema. It mirrors the shapes the backend
actually returns, so you can import them in any client component instead
of hand-rolling `type Lead = { id: number; name: string; ... }`.

## Regenerate

```bash
npm run api:codegen
```

By default it fetches from `http://127.0.0.1:8000/api/schema/`. Override
the host with `PLAYWRIGHT_API_URL=https://api.example.com` if needed.

The script requires the API to be running. Add `--check` (TODO) to make it
CI-friendly.

## Usage

```ts
import type { components } from "@/lib/api-types";

type Lead = components["schemas"]["Lead"];
type AuditEntry = components["schemas"]["UserAuditActivity"];
```

Components, hooks, and workspaces should prefer these types over local
ad-hoc declarations. When the backend schema changes, regenerate and
TypeScript will surface every call site that needs to be updated.

## When the codegen fails

1. Make sure Django is running and reachable at `PLAYWRIGHT_API_URL`.
2. Run `python manage.py spectacular --validate` to find schema errors.
3. Delete `lib/api-types.ts` and re-run `npm run api:codegen`.
